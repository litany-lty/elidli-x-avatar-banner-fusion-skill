# 生成提示词模板与局部修正词

## A. 一次生成用母提示词

```text
任务：制作适配 X/Twitter 个人主页的真实可上传横幅背景，不是主页合成图。
画布比例严格 3:1，推荐 1536×512 或更高分辨率的 3:1。禁止生成头像、头像占位圆、社交平台 UI、文字、签名或水印。

画面主题：【主题】
风格：【风格】
主体：【主体对象与动作】，置于【主体位置，例如右侧 60%～85%】。
配色：【主色、辅色、对比色】。
连接媒介：【光带/云气/水流/粒子/枝叶/火焰/花瓣/星轨/几何轨迹】。

关键适配：X 的真实圆形头像将由客户端叠加在横幅左下角，头像圆心位于横幅底边以下，仅顶部一小段弧形压进横幅。不要在背景里绘制完整头像或完整圆环。需要在背景左下角、极靠近底边的真实接触区，布置一条低位、细而柔和的弧形亮边/流光源点，让它沿未来头像上沿顺势延伸。光流从此处自然向右汇入主体，使真实头像叠加后仿佛与画面发生光线/能量互动。

若使用 1536×512 的经验性移动端参考值：未来头像中心大约在 (210, 617)，半径约 158；圆弧顶端在 y≈459；左下交互主区域在 x≈70–350、y≈415–512；亮边可高于真实圆弧顶部约 0–40px。上述数值仅作首稿参考；如果有实际截图测算值，必须全部以测算值替换。

底部地表、山脊或暗色空带尽可能轻薄，亮弧不得在头像上方孤悬，也不要让圆弧中心被错误放到横幅内部。状态栏和操作按钮可能遮挡上方与右侧细节；保持主体的视觉可辨性与画面层次。整体应是独立完整的横幅，叠加真实头像后才产生第二层视觉互动。

负面要求：头像、圆形占位图、完整圆框、人工合成的真实 X 截图、跨越到横幅外的可编辑图层、厚重黑土、大片无内容底部黑带、孤立光环、严重遮挡主体、可见文字与标记。
```

## B. 基于实际截图的精准替换段

把 A 中的经验性参数替换为以下文字：

```text
本次已有真实应用截图，已按横幅显示矩形反算到 3:1 原图：头像圆心为 (【CX】,【CY】)，半径 【R】；横幅宽高 【W】×【H】，头像上沿 y=【TOP】，横幅底边 y=【H】，可见重叠高度 【OVERLAP】。必须将左下亮弧的顶部置于 y≈【TOP】 附近（允许适度上方外发光）、保持低位，与头像圆弧几何吻合；连接的光流沿浅弧外侧流向画面右侧。不得再使用默认经验值或在图内另外画一个完整头像圆框。
```

## C. 单向改动补充提示词

- **太高**：`保持主题、主体、配色、横向光流基本不变；把左下浅弧及交汇光效垂直下移【N】像素（以 1536×512 为基准），削减下方不必要的暗色土地/空带。背景图仍保持 3:1，不增加完整圆盘。`
- **太低**：`保持主体不变；只将左下浅弧上移【N】像素，使其顶部露在未来头像上沿附近；横幅底部仍然不绘制完整圆框。`
- **偏左/偏右**：`左下弧顶目标 x=【X】；只平移局部互动弧与光流源头，不修改真实头像位置、不移动整体布局。`
- **黑色边框太显眼**：`不能改变平台头像黑框；降低其周围背景反差，光源沿圆弧最靠上的边缘柔和擦亮，并用低亮度紫蓝过渡接续到画面，避免高亮完整圆线和第二重暗边。`
- **底部黑土太厚**：`减少底部暗色土地高度，把发光地平线压到靠近底边；不要让原来的大块黑色地表重新出现。`
- **主体太靠近按钮**：`保持头像融合区稳定，主体整体向【方向】移动【比例】，确保最重要的头部/标志避开顶部状态栏和右侧按钮。`

## D. 输出合同

最终只交付：

- 一张 3:1 **纯背景图**（PNG/JPG 均可，PNG 优先精修）。
- 可选一张用于人工确认的**合成对位预览**，须清晰标记为 PREVIEW，**不可作为背景上传**。
- 可选 `layout.json` 和短说明。**不得把对位辅助圆绘制在最终横幅中。**
